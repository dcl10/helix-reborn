# helix-core

Shared library for Helix Reborn's Python services (EDA, training and evaluation workers). It never runs on its own.

See [docs/python-services.md](../../../docs/python-services.md) for the workspace layout and conventions, and
[docs/architecture.md](../../../docs/architecture.md) for what belongs here versus in a service.

## Modules

- `helix_core.logging`: JSON logging configuration for stdout.
